# 配置说明

所有配置都在这里。代码里没有写死任何人的密钥、地址或口令，全部由你自己配置。

## 在哪里配置

| 运行方式 | 怎么配置 |
|---|---|
| **本机运行**（`python3 run.py`） | 打开页面后点右上角"模型"，在设置窗口里填写。保存在 `local-data/config.json`。也可以用下面的环境变量 |
| **Render 线上** | Render 控制台 → 点 `ai-npc-drama` 服务 → 左侧 **Environment**。改完保存，服务会自动重启 |
| **Docker** | `docker run -e OPENAI_API_KEY=… -e NPC_BASE_URL=… -p 8800:8800 ai-npc-drama` |

线上部署后，用管理员口令登录，页面里的"模型"设置也能改（密钥除外）。页面里改过的设置存在数据库里，**优先于**环境变量。

## 必填项（线上部署时）

| 变量 | 说明 | 例子 |
|---|---|---|
| `OPENAI_API_KEY` | 模型服务的密钥。用 OpenAI 官方就填 OpenAI 的密钥；用中转服务就填中转服务给你的密钥 | `sk-...` |
| `NPC_BASE_URL` | 模型服务地址，必须兼容 OpenAI 的 Chat Completions 接口。程序会在后面自动加 `/chat/completions` | OpenAI 官方：`https://api.openai.com/v1`<br>中转服务：按它提供的地址填，有的要带 `/v1`，有的不要 |
| `ACCESS_CODE` | **体验口令**，发给来玩的人。设置了它，程序才会进入"线上模式"（要口令才能进） | `风雪夜归人` |
| `ADMIN_CODE` | **管理员口令**，只有你自己知道，必须和体验口令不同。管理员能看所有玩家、心智面板、用量和导出数据 | `my-admin-8371` |

## 模型相关（可选）

| 变量 | 默认 | 说明 |
|---|---|---|
| `NPC_MODEL` | `gpt-6.1-sol` | 主模型：对白、导演场景、专属台词、记忆整理、生活推演都用它。填你的模型服务实际支持的名字 |
| `NPC_FAST_MODEL` | 空（同主模型） | 生成"回复选项"用的模型，可以换一个更便宜更快的 |
| `NPC_REASONING_EFFORT` | `low` | 推理强度：`low` 快，`medium` 更深思但更慢。**模型服务不认这个参数时填 `none`** |
| `NPC_MAX_TOKENS_PARAM` | `max_completion_tokens` | 有些兼容服务只认 `max_tokens`，报参数错误时改成 `max_tokens` |
| `NPC_JSON_MODE` | `1` | 是否要求模型输出 JSON 格式（`response_format`）。服务不支持就填 `0` |
| `NPC_STREAM_USAGE` | `1` | 流式输出时是否请求用量统计（`stream_options`）。服务不支持就填 `0`，代价是"用量"窗口统计不到对白的费用 |
| `NPC_TIMEOUT` | `60` | 单次请求超时（秒） |
| `NPC_MODE` | 填了密钥就是 `live` | `mock` = 模拟模式，不调用模型，只看流程 |

## 线上运营（可选）

| 变量 | 默认 | 说明 |
|---|---|---|
| `SHOW_MIND` | `0` | `1` = 所有人都能看"心智面板"（NPC 的记忆、日记、原话、传话和心事进度）；`0` = 只有管理员能看。注意：心智面板会剧透 |
| `TURNS_PER_MINUTE` | `10` | 每个访客每分钟最多说几句，防止刷额度。管理员不受限 |
| `TURNS_PER_DAY` | `300` | 每个访客每天最多说几句。同一个 IP 的额度是这两项的 3 倍（一个 IP 下可能有好几个人） |
| `TURNS_TOTAL_PER_DAY` | `0`（不限） | 所有访客加起来每天最多说几句，用来兜住费用 |
| `PRICE_INPUT` / `PRICE_CACHED` / `PRICE_OUTPUT` | `2` / `0.1` / `10` | 每百万 token 的价格（美元），只用来在"用量"窗口里估算费用。换了模型就按它的价格改 |

## 自动处理，不用管

| 变量 | 说明 |
|---|---|
| `DATABASE_URL` | Render 自动填，连接免费 PostgreSQL。本机不设置时用 `local-data/world.sqlite3` |
| `SESSION_SECRET` | 登录凭证的签名密钥。Render 自动生成；不设的话，程序第一次启动时随机生成一个存进数据库 |
| `ALLOWED_HOSTS` | 本机模式（没设 `ACCESS_CODE`）只接受用 `localhost` / `127.0.0.1` 打开，防止别的网页偷偷读写你的服务。想用别的地址（比如局域网 IP）打开，就把它写在这里，逗号分隔。注意本机模式下谁打开都是管理员，能看到全部数据、改模型配置 |
| `PORT` / `HOST` / `DATA_DIR` | Render 自动设置端口。本机默认 `127.0.0.1:8800`、数据在 `local-data/` |
| `CONTENT_DIR` | 用哪个内容包，默认是仓库里的 `content/`。写了自己的故事就指过去 |

## 剧情和人物在哪里改

全部在内容包里（默认 `content/`），详见 [内容包写作指南](内容包写作指南.md)。

| 想改的 | 位置 |
|---|---|
| 标题、玩家建档、每章对话预算、事件分组、界面文案 | `content/pack.json` |
| 世界背景 | `content/world.md` |
| 玩家角色的人设（只用于生成回复选项） | `content/player.md` |
| 某个 NPC 的性格、说话方式 | `content/npcs/<id>/bible.md` |
| 他的心事，以及每一章解锁到哪里 | `content/npcs/<id>/secret.md` |
| 他的名字、地点、表情、心声、传话关系 | `content/npcs/<id>/npc.json` |
| 每一章的 CG、导演卡、章末钩子、每个人这一章的状态 | `content/story/NN.json` |
| 经营、调查、有选择的事件、消息 | `content/events.json` |
| 线索；指认和结局 | `content/clues.json`；`content/endings.json` |
| 给模型的提示词（通用的，不含剧情） | `npc/prompts.py` |
| 插画和头像 | `content/assets/cg/`、`content/assets/avatars/` |

改完先跑 `python3 tools/check_content.py`，再重启（本机重新运行；线上推到 GitHub，Render 会自动重新部署）。

## 常见问题

**回复里出现"模型服务返回 400"，提到某个参数不认识**
按提示改对应的开关：`reasoning_effort` → `NPC_REASONING_EFFORT=none`；`max_completion_tokens` → `NPC_MAX_TOKENS_PARAM=max_tokens`；`response_format` → `NPC_JSON_MODE=0`；`stream_options` → `NPC_STREAM_USAGE=0`。

**"模型服务返回 401"**
密钥不对，或者密钥和服务地址不匹配（比如拿 OpenAI 官方的密钥去连中转服务）。

**"模型服务返回 404"**
服务地址不对，多半是少了或多了 `/v1`。

**偶尔"模型服务返回 502"**
中转服务的临时问题。程序会自动重试一次；还不行就再说一遍。记忆整理失败会在下次自动补做，不会丢。

**回复太慢**
把 `NPC_REASONING_EFFORT` 设成 `low`，或者把 `NPC_FAST_MODEL` 设成更快的模型。

**页面一直显示"模拟"的固定对白**
没有填密钥，或者 `NPC_MODE` 被设成了 `mock`。启动时终端（或 Render 的 Logs）里那一行会写明是"模拟模式"还是"真实模式"。

**安全提醒**
服务地址如果是 `http://` 而不是 `https://`，密钥和对话内容在网络上不加密传输。做 Demo 没问题，但这个密钥最好不要和其他重要服务共用。
