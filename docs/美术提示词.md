# 《雪痕》美术提示词

用途：示例故事的人物设定图、CG、场景、头像和主视觉，拿去即梦、通义万相、Midjourney、Stable Diffusion 等工具生成。
每条都给了中文版和英文版：中文适合即梦、通义万相，英文适合 Midjourney、SD。

---

## 关于画风

参考 2000 年代国产单机古风 RPG 的过场插画：干净的勾线，柔和的分色上色叠一层淡彩，人物秀气、比例偏写实，背景是手绘的山水和建筑，带一点怀旧感。

**提示词里不写任何游戏或作品的名字，只描述画风。** 写了名字，生成工具容易直接照着那部作品的人物去画，这样的图不能放进开源仓库。同样，不要拿任何作品的原画当参考图。另外，人物不要像任何真人。

---

## 使用建议

1. **先出人物设定图**（第一节），挑满意的作为后面所有 CG 和头像的**参考图**。即梦、通义万相用"参考图 / 角色一致性"功能，Midjourney 用 `--cref`。同一个人在每张图里长得一样，靠的就是这一步。
2. **每条提示词 = 统一画风 + 这一张的内容**。画风那一段每次都原样带上。
3. **玩家不露脸，也看不出男女。** CG 一律用第一人称视角，画面就是"你"的眼睛，最多露出一只手，而且是**左手**。这样男女玩家都能代入，也合"从没人看清过一刀雪的脸"这个设定。
4. **不画血腥**：死者用草席盖住，最多露一只手；伤口不特写。
5. **尺寸**：CG、场景、主视觉都是 16:9 横图，建议 1920×1080 或更大；头像是正方形，512×512。
6. **优先级**：标 ★ 的是必做的，其余可选。缺了的图会显示文字场景卡或代码画的临时头像。
7. **文件名**照每条后面写的来，放进 `content/assets/cg/` 和 `content/assets/avatars/`，刷新页面就会自动替换。扩展名不限：png、jpg、webp 都认。生成的 PNG 往往一张好几 MB，建议转成 webp（质量 80 左右）再放进去，画质看不出差别，网页加载快得多。
8. **授权**：确认你用的生成工具允许把生成的图放进开源仓库再分发。

### 用 ChatGPT（Images 2.0）生图

提示词照用，用法上有几处不同：

1. **没有负面提示词栏。** 把下面"通用负面提示词"的意思写成一句话，加在每条末尾：「画面里不要有任何文字、水印和签名，不要现代物品，不要血腥，人物不要像任何真人。」文字这条最要紧：它很会写字，古风场景里常自己在灯笼、牌匾上加汉字。
2. **一致性靠上传参考图。** 每张 CG 和头像都把对应人物的设定图传上去，写明「图1是谢不归的设定图，脸、发型、服装保持一致」。一张图里有几个人就传几张，按顺序编号说明。它不记得别的对话，换了对话要重新上传。
3. **比例写进提示词**：CG 写「16:9 横图」，头像写「1:1 正方形」。
4. **盯住左右手。** 写明「露出的是左手，从画面左下方伸进来」；画反了就说「这是右手，改成左手，其他不变」。
5. **在同一个对话里改。** 不满意就说「保持构图不变，只把……改成……」，比重新生成更稳。
6. **头像一次一张**：传设定图，写「同一个角度、同一身衣服、同一个背景，只换表情」。
